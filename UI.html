Straighten the film.
Keep the coordinates true.

A batch pipeline for X-ray, MRI, and CT scans. It corrects tilt, strips the scanner's black border, boosts contrast, and carries every polygon and box through the same transform — so your annotations still line up on the other side.

Launch app See how it works

Six steps, every shape carried through

Each scan moves through the same sequence, whether it arrives dead straight or photographed at an angle on a lightbox.

1

Deskew

Finds the film's corners against its background and perspective-warps it flat.

2

Crop border

Removes the near-black scanner margin, with a small safety border kept.

3

Enhance

CLAHE contrast brings out bone edges and soft tissue detail.

4

Resize + pad

Fits a square canvas at your chosen size, aspect ratio kept, median-padded.

5

Transform

Every polygon and rectangle follows the same math as the pixels around it.

6

Sort

Annotated scans are filed into folders by class, ready to train on.

Built for a folder of scans, not one at a time

Drop in a batch, get back a dataset

Upload scans alongside their LabelMe-style JSON — and an optional plain-text label file for shapes that didn't get one — and the app returns a single ZIP: cleaned images, transformed JSON, annotated overlays, and a class-sorted copy of both, all matched by filename.

Fault-tolerant

One corrupt file is skipped and logged — the rest of the batch still finishes.

Live progress

See which scan is processing and how many are left.

Class legend + counts

A color key and per-class shape totals appear after each run.

processing_report.json

Settings used, per-class counts, and any skipped files, bundled in the ZIP.

What comes back in the ZIP

Ready to hand to a training script as-is, or to inspect folder by folder first.

clean_images/          # preprocessed grayscale PNGs
clean_json/            # JSON, coordinates matched to clean_images
annotated_images/      # shapes drawn on, for a quick visual check
label_wise_dataset/    # annotated images + JSON, sorted by class
processing_report.json # run settings, class counts, skipped files
